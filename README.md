# ImportNow – Import Directly from China to India

A modern, responsive website designed to showcase ImportNow's China-to-India import services.

## Live Website
https://import-now-website-omega.vercel.app/

## Features
- Responsive website design
- Hero section with 3D visual elements
- Importing services and product categories
- Step-by-step importing process
- Company information and contact section
- Interactive navigation

## Technologies Used
- React
- TypeScript
- Vite
- Three.js
- CSS
- GitHub
- Vercel

## AI Tools Used
- Google AI Studio (Gemini) for AI-assisted website development and code generation.

## Deployment
Hosted on Vercel.
